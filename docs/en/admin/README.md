# Administration

This section is for whoever uses the `admin` account: it sets up BiblioViva after the installation and manages the staff
accounts, the classes, the imports, the print templates and the backups. The first steps give the order of the first
settings; the guides explain one task at a time; the screen pages describe the pages of Administration.
