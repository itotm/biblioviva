# Compliance

This section gathers what the rules ask of a school that adopts BiblioViva, what BiblioViva does about it and what is
left to the school. It is written for the head teacher, the school's administrative manager (DSGA), the data protection
officer (DPO) and the officer for digital transition (RTD).

The pages give the facts useful for the school's evaluations, each one checked in BiblioViva's code; the decisions
belong to the school and its DPO, and the pages are not legal advice. Where the rule leaves a point open, the page says
so.

| Area | Rule | Page |
|---|---|---|
| Data protection | GDPR, D.Lgs. 196/2003 | [Personal data protection](data-protection.md) |
| Accessibility | Law 4/2004, AgID guidelines | [Accessibility](accessibility.md) |
| Free software in public administration | CAD, art. 68–69 | [Free software](open-source.md) |
| IT security | AgID minimum measures, ACN cloud regulation | [Security](security.md) |

The whole section can be downloaded as a single PDF file from the documentation site.
