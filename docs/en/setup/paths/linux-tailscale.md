# PC with Linux and Tailscale

This path installs BiblioViva on a PC with Debian or Ubuntu and makes it reachable with Tailscale (the full way:
secure address, camera, phones, use from outside the school too). The steps are carried out in order: each ends with a
check to pass before going on to the next.
