# Add a copy to a book already in the catalogue

This guide explains how to add one or more copies to a book that already has a record, for example when the library
receives a second copy or a gift of the same title. It is for whoever catalogues the books.

- Time: about 1 minute.
- Account: "Cataloguing" (also "Administration").
- Requirements: the book and, for the first method, the USB barcode scanner.

Each copy has a code of its own, generated by BiblioViva, and a label of its own. The record of the book (title, author,
classification, material) stays a single one and is not written again.

## Procedure

### Add the copy by reading the ISBN

1. Open **Catalogue** and press **New book**.
1. Read with the scanner the ISBN barcode. BiblioViva finds the record already in the catalogue and shows "This ISBN is
   already in the catalogue", with the title and the number of copies the book already has.

   <!-- figure: catalog/new-book-duplicate | The New book page facing an ISBN already in the catalogue -->

1. Write in the **Number of copies** field how many copies are added.
1. Press **Add copy**. The confirmation opens, with the summary "N copies added to …" and the **Copy barcodes**. The
   new copies take the **Call number** of the book, computed by BiblioViva; the material is the one of the record.
1. To go on press **Add another** (the next book), **Print labels** or **Open the record**.

### Add the copy from the record of the book

This method is for a book without an ISBN or when the level or other data of the copy need to be
changed.

1. Open **Catalogue** and search for the book, see [Find a book](find-a-book.md). Open its record.
1. Press **Add copies**. If the browser window is narrow the button is in the menu of the other actions at the top. The
   "Add copies" window opens.

   <!-- figure: catalog/add-copies-dialog | The Add copies window on the record of a book -->

1. Write the **Number of copies** (from 1 to 100).
1. Check the **Call number**, shown with the note "Computed from the classification, the level and the author.":
   BiblioViva computes it by itself and it is not typed. It is the code that says where the book goes on the shelf, for
   example `B 4 DEL` or `590 ROS`; its form depends on the scheme the library has chosen, see
   [Change the classification and the reading levels](../../admin/guides/classification.md).
1. If the **Call number text** field appears ("The part of the call number written for this copy."), write that part.
   With the free scheme the field is called **Call number** and the whole call number is typed.
1. If the library assigns the reading level to each copy, choose the **Level of the copy**: the call number of the copy
   carries its own level.
1. If the book is in several volumes, write the number in the **Volume / number** field.
1. Check the **Acquisition date** and, if needed, write a note in **Notes on the copy**.
1. If the copy must not leave the library, for example a volume to consult on the premises, tick **Reference only (not
   lent)**.
1. Press **Add**. A notice confirms "N copies added" with the assigned codes, and the copies appear in the **Copies**
   tab.
1. To print the labels press **Print labels** at the top of the record, or the printer icon on the row of the copy, see
   [Print book labels](print-book-labels.md).

## Result

The record of the book shows the additional copies, each with its code, its call number and the status **Available**.
The number at the top, "N available of M", includes the new copies. The **Labels** column says **Labels to print** until
the labels are printed.

## Possible problems

### The book is not found by reading the ISBN

The book already has a record but it is not found by reading the ISBN: the record was written without an ISBN, or with
a different ISBN (another edition). Search for it by title in **Catalogue** and use the second method.

### The number of copies is out of bounds

"1 to 100 copies at a time" appears: the number of copies is out of bounds. Add fewer copies at a time.

### The record is still to be classified

The record is marked "To classify": the copies are added all the same, but they are not lent and have no call number
until the book is classified, see [Classify books](classify-books.md).

### The book has several volumes

The copy added belongs to a book in several volumes: add one copy at a time, writing the number in **Volume /
number**.

### A copy was added by mistake

A copy that was never lent is deleted from its row with the trash icon, which asks for confirmation; a copy already
lent is removed as in [Withdraw a lost or damaged copy](withdraw-a-copy.md).
