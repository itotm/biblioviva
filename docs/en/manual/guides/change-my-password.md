# Change your own password

This guide explains how to choose a new password for the account you work with in BiblioViva. It is for everyone who
uses BiblioViva, with any account: each account changes its own password.

- Time: 2 minutes.
- Account: any.
- Requirements: the current password and the new one, at least 8 characters long.

## Procedure

1. Press, at the top right, the name of the account or, if the screen is narrow, the icon of the person. The account
   menu opens.
1. Choose **Change password**. The **Change password** page opens.
1. Type the password in use in the **Current password** field.
1. Type the new password in the **New password (at least 8 characters)** field.
1. Type the new password again in the **Repeat the new password** field.
1. Press **Save the password**. The message "Password changed" appears.

> [!IMPORTANT]
> The password cannot be seen again: BiblioViva keeps only a protected form of it. Note it down in a safe place.

To give up without changing anything, press **Cancel**.

## Result

- The account logs in with the new password; the old one is no longer valid.
- The device in use stays signed in. The other devices signed in with the same account must sign in again with the new
  password: the page reminds of it with the note "After the change, the other devices signed in with this account must
  sign in again with the new password."

## First login with a password given by the administrator

When the administrator creates a personal account, the **To change at the first login** box is normally left ticked. At
the first login with that account BiblioViva opens only the **Change password** page, with the note "The password of
this account was given by the administrator: choose your own before going on." Any other page leads back there.

1. Type in the **Current password** field the password received from the administrator.
1. Follow steps 4, 5 and 6 of the procedure above.

On the page there is **Log out** instead of **Cancel**: press it to leave without changing the password.

## Possible problems

### The current password is not right

"The current password is not right." appears: retype the password in use. If it has been lost, the administrator gives a
new one, as described in [Change a password](../../admin/guides/change-a-password.md).

### The new password is the same as the current one

"The new password is the same as the current one." appears: choose a different password.

### The password is too short

"The password must have at least 8 characters." appears: choose a longer password.

### The two passwords are not the same

"The two passwords are not the same." appears: retype the password in the **Repeat the new password** field.

### The Save the password button stays off

One of the three fields is empty or the new password is too short.

### In the public demo the password cannot be changed

The page warns: "In the public demo the accounts belong to every visitor: the password is not changed."
