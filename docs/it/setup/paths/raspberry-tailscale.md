# Raspberry Pi con Tailscale

Questo percorso installa BiblioViva su un Raspberry Pi e lo rende raggiungibile con Tailscale (il modo completo:
indirizzo sicuro, fotocamera, telefoni, uso anche fuori dalla scuola). I passi vanno eseguiti nell'ordine: ciascuno
termina con una verifica da superare prima di passare al successivo.
