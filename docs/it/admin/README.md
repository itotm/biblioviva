# Amministrazione

Questa sezione è per chi usa l'account `admin`: imposta BiblioViva dopo l'installazione, gestisce gli account del
personale, le classi, le importazioni, i modelli di stampa e le copie di sicurezza. I primi passi indicano l'ordine
delle prime impostazioni; le guide spiegano un compito alla volta; le pagine delle schermate descrivono le pagine di
Amministrazione.
