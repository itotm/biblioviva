# Manuale

Il manuale è per chi lavora al banco prestiti, cataloga i libri, iscrive gli utenti e stampa tessere ed etichette.
Le guide spiegano un compito dall'inizio alla fine, passo per passo; le pagine delle schermate descrivono ogni
schermata con le sue parti e i suoi messaggi. Il lettore di codici a barre USB è lo strumento normale per leggere
tessere, copie e ISBN; il telefono è facoltativo.

In ogni pagina di BiblioViva il pulsante **Guida** apre in una nuova scheda la pagina della documentazione che spiega
proprio quella schermata: sul computer è in alto a destra, sul telefono è il pulsante rotondo con il punto di
domanda accanto al titolo della pagina.
