# Cambiare la propria password

Questa guida spiega come scegliere una nuova password per l'account con cui si lavora in BiblioViva. Serve a chiunque
usi BiblioViva, con qualsiasi account: ogni account cambia da sé la propria password.

- Tempo: 2 minuti.
- Account: qualsiasi.
- Occorrente: la password attuale e la nuova, di almeno 8 caratteri.

## Procedura

1. Premere in alto a destra il nome dell'account o, se lo schermo è stretto, l'icona della persona. Si apre il menu
   dell'account.
1. Scegliere **Cambia password**. Si apre la pagina **Cambia password**.

   <!-- figure: account/change-password | La pagina Cambia password con i tre campi -->

1. Scrivere la password in uso nel campo **Password attuale**.
1. Scrivere la nuova password nel campo **Nuova password (almeno 8 caratteri)**.
1. Scrivere di nuovo la nuova password nel campo **Ripetere la nuova password**.
1. Premere **Salva la password**. Compare il messaggio «Password cambiata».

> [!IMPORTANT]
> La password non si rivede più: BiblioViva ne conserva soltanto una forma protetta. Annotarla in un posto sicuro.

Per rinunciare senza cambiare nulla, premere **Annulla**.

## Risultato

- L'account entra con la nuova password; la vecchia non vale più.
- Il dispositivo in uso resta collegato. Gli altri dispositivi collegati con lo stesso account devono rientrare con la
  nuova password: la pagina lo ricorda con la nota «Dopo il cambio, gli altri dispositivi collegati con questo account
  devono rientrare con la nuova password.»

## Primo accesso con una password data dall'amministratore

Quando l'amministratore crea un account personale, di norma lascia attiva la casella **Da cambiare al primo accesso**.
Entrando per la prima volta con quell'account, BiblioViva apre soltanto la pagina **Cambia password**, con la nota «La
password di questo account è stata data dall'amministratore: prima di continuare, sceglierne una propria.» Qualsiasi
altra pagina riporta lì.

1. Scrivere nel campo **Password attuale** la password ricevuta dall'amministratore.
1. Seguire i passi 4, 5 e 6 della procedura sopra.

Nella pagina c'è **Esci** al posto di **Annulla**: premerlo per uscire senza cambiare la password.

## Possibili problemi

### La password attuale non è giusta

Compare «La password attuale non è giusta.»: riscrivere la password in uso. Se è stata persa, l'amministratore ne dà una
nuova, come descritto in [Cambiare una password](../../admin/guides/change-a-password.md).

### La nuova password è uguale a quella attuale

Compare «La nuova password è uguale a quella attuale.»: scegliere una password diversa.

### La password è troppo corta

Compare «La password deve avere almeno 8 caratteri.»: scegliere una password più lunga.

### Le due password non sono uguali

Compare «Le due password non sono uguali.»: riscrivere la password nel campo **Ripetere la nuova password**.

### Il pulsante Salva la password resta spento

Uno dei tre campi è vuoto o la nuova password è troppo corta.

### Nella demo pubblica la password non si cambia

La pagina avvisa: «Nella demo pubblica gli account sono di tutti i visitatori: la password non si cambia.»
